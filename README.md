# 🚀 TeamSync

A modern **Full Stack Team Collaboration Platform** built with **Django REST Framework**, **React**, **JWT Authentication**, and **WebSockets**.

---

## 📌 Overview

TeamSync is a collaborative workspace application where users can manage tasks, communicate in real time, share files, and receive notifications. The project demonstrates a complete full-stack workflow using Django for the backend and React for the frontend.

---

## ✨ Features

- 🔐 JWT Authentication
- 📊 Dashboard with task overview
- ✅ Task Management (Create, Read, Update, Delete)
- 💬 Real-Time Chat using WebSockets
- 📎 Image & File Sharing in Chat
- 🔔 Notifications
- 👥 Workspace-based collaboration
- 📱 Responsive Bootstrap UI

## ⚙️ Installation

### Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
